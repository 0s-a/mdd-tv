## 2. معايير تسمية حزم الأرشيف (Naming Conventions)

تتبع حزم الأرشيف النمط القياسي الموحد التالي (ملف مستقل لكل بناء دون تكرار):
`mdd_tv_v{versionName}_b{versionCode}_{buildType}_{YYYYMMDD}.apk`

* `mdd_tv`: معرف التطبيق.
* `v1.0.2`: رقم الإصدار الدلالي (Semantic Version).
* `b3`: رمز البناء الداخلي (`versionCode`).
* `release`: نوع البناء (مضغوط وموقع ومشفّر بـ R8).
* `YYYYMMDD`: تاريخ البناء بصيغة ISO المصغرة.

---

## 3. أمر التثبيت عبر ADB

لتثبيت أي حزمة من الأرشيف مباشرة على جهاز Android أو Android TV:
```bash
adb install -r /mnt/date/my_project/jellyfin-workspace/mdd_tv/releases/<اسم_الحزمة>.apk
```
