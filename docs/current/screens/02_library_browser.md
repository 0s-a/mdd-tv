## 1. القرارات الجوهرية المعمارية (V2.2.0 Key Decisions)

1. **اعتماد التصفح الهرمي الصافي (Pure Hierarchical Navigation):**
   * يتم استعراض المكتبة شجرياً وفق هيكلية وسائط Jellyfin الأصلية: مكتبة -> مجلدات -> مسلسلات -> مواسم -> أعمال.
   * الاستعلام دائماً يكون غير تكراري (`recursive = false`) للمجلد الحالي، مما يحمي الخادم وذاكرة العتاد ويضمن سرعة استجابة فورية (<50ms).
   * إزالة النمط المسطح القديم وزر التبديل المزدوج لتقليل التعقيد البرمجي والتشتت الذهني.

2. **إلغاء كبسولات الفلاتر الثابتة (No Static Filter Chips):**
   * إزالة كبسولات (4K UHD فقط، تقييم +8.0، والمفضلة) من شاشة المكتبة لحماية مؤشرات الترقيم (`startIndex`) من التعطل أو التكرار.
   * توجيه عمليات البحث والتصفية المتقدمة إلى شاشة البحث المخصصة (`SearchScreen`).
   * توفير 56dp رأسياً لصالح شبكة الأعمال.

3. **إلغاء شريط القفز الأبجدي وتناظر الشبكة (Symmetrical 3-Column Grid):**
   * إزالة شريط الحروف الجانبي لعدم الحاجة له في التصفح الهرمي ذي المجموعات المركزة.
   * ضبط هوامش الشبكة لتكون متناظرة تماماً في كلا الطرفين (`start = 16dp, end = 16dp`).

4. **تأمين مسار المجلدات والترتيب المدمج (`BreadcrumbsBar`):**
   * شريط تفاعلي يعرض مسار المجلدات الحالي مع إمكانية القفز لأي مجلد أب، وزر رجوع فوري عند التعمق في المجلدات.
   * دمج زر الترتيب بشكل أنيق ومدمج في الطرف المقابل لمسار المجلدات.

5. **تأمين مساحة شريط التنقل السفلي العائم:**
   * ضبط الهامش السفلي للشبكة بـ `bottom = LocalBottomClearance.current + 16dp` لضمان ظهور آخر صف بالكامل فوق كبسولة التنقل العائمة.

## 3. الربط الشبكي والمعمارية الهرمية

1. **جلب عناصر المجلد النشط:**
   * `GET Users/{userId}/Items?parentId={folderId}&sortBy={SortCriteria}&sortOrder={Descending/Ascending}&recursive=false&includeItemTypes=Folder,Series,Movie,Episode,Video,Audio`
2. **الترقيم اللانهائي (Infinite Pagination):**
   * استرجاع الدفعات بحجم 60 عنصراً بالاعتماد على الفهرس الدقيق للمحتويات القادمة من السيرفر.
3. **الروابط الديناميكية للبوسترات والبدائل:**
   * `$serverUrl/Items/{itemId}/Images/Primary?fillWidth=300&quality=85` مع كاش Coil.
   * في حال غياب البوستر أو تعذر تحميله، يتم تصيير بطاقة سينمائية ناعمة بأيقونة متوهجة واسم العمل، مما يمنع ظهور فراغات سوداء مشوهة.
