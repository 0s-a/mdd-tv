## 1.  التغييرات الجوهرية في الإصدار الثاني (V2 Key Decisions)

1. **فلترة المفضلة المحلية (Local-First Favorite Filter):**
   * في V1 القديم: كان الفلتر يستعلم السيرفر بـ `filters="IsFavorite"`.
   * **في V2 المعتمد:** نظراً لأن المفضلة أصبحت معزولة محلياً في `Room DB` (`LocalFavoriteEntity`)، يقوم الفلتر بمطابقة معرّفات مكتبة السيرفر مع جدول المفضلة المحلي في الرام، دون إرسال أي استعلام للسيرفر المشترك.
2. **سلاسة شريط الحروف الأبجدي (A-Z Scrubbing):**
   * القفز السريع محلياً باستخدام `animateScrollToItem` لحماية السيرفر من فيضان الطلبات الشبكية أثناء سحب الحروف.
3. **تأمين مساحة شريط التنقل السفلي العائم (Android 15 Clearance):**
   * ضبط الهامش السفلي للشبكة بـ `contentPadding = PaddingValues(bottom = 120.dp)` لضمان ظهور آخر صف بالكامل فوق كبسولة التنقل العائمة.

## 3.  الربط الشبكي والمعمارية المحلية

1. **جلب عناصر المكتبة:**
   * `GET Users/{userId}/Items?parentId={libraryId}&sortBy=SortName&sortOrder=Ascending`
2. **تطبيق فلتر المفضلة محلياً في الـ ViewModel:**
   ```kotlin
   fun applyFavoritesFilter(items: List<MediaItem>, localFavorites: Set<String>): List<MediaItem> {
       return if (isFavoriteFilterActive) {
           items.filter { localFavorites.contains(it.id) }
       } else {
           items
       }
   }
   ```
3. **الروابط الديناميكية للبوسترات:**
   `$serverUrl/Items/{itemId}/Images/Primary?fillWidth=300&quality=85` مع كاش Coil التلقائي.
