## 2.  تفصيل المكونات والرموز البرمجية (Design Tokens)

### 2.1 حقل إدخال الاسم (Display Name Field)
* **الشكل:** `OutlinedTextField` زجاجي بخلفية `JellyfinColors.SurfaceGlass`.
* **الحد التفاعلي عند التركيز:** `PrimaryIndigo #6366F1` (لون التفاعل الموحد).
* **الحد الأقصى للأحرف:** 20 حرفاً.
* **نص التلميح الافتراضي:** `"اكتب اسمك هنا..."`.

### 2.2 شبكة الأفاتار الرمزية (8 شخصيات)
```kotlin

    AvatarItem("avatar_1", ""),  // ممثل
    AvatarItem("avatar_2", ""),  // أسد

    AvatarItem("avatar_4", "️"),  // عميل سري
    AvatarItem("avatar_5", "⭐"),  // نجم

```
* **الحجم والمظهر:** بطاقة دائرية زجاجية `64.dp x 64.dp`.
* **الأفاتار المحدد:** حلقة توهج بلون `PrimaryIndigo #6366F1`.
* **الأفاتار الافتراضي:** `avatar_1` محدد تلقائياً عند فتح الشاشة لأول مرة.

### 2.3 زر الدخول الرئيسي وزر التخطي السريع
* **زر الدخول:** تدرج أفقي `PrimaryIndigo #6366F1` مع اهتزاز لمسي خفيف `HapticFeedbackType.LongPress`.
* **زر التخطي:** زر نصي صامت يحفظ فوراً الاسم الافتراضي `"مشاهد مدد"` مع `avatar_1` وينقل للشاشة الرئيسية خلال أجزاء من الثانية.

## 3.  منطق التنقل (Navigation Logic)

```kotlin
// داخل OnboardingViewModel.kt
fun onConfirmProfile(name: String, avatarKey: String) {
    viewModelScope.launch {
        val finalName = name.ifBlank { "مشاهد مدد" }
        val finalAvatar = avatarKey.ifEmpty { "avatar_1" }

        localProfileRepository.createProfile(
            displayName = finalName,
            avatarKey = finalAvatar
        )

        _navigationEvent.emit(NavigationEvent.GoToHome)
    }
}
```
