## Screen 05 — Search & Explore Transparent Modal Window
### وثيقة المواصفات الفنية: نافذة شفافة حوارية، فلاتر ديناميكية حية، واستكشاف ذكي بدون بيانات ثابتة

> **المرجع المعماري:** `docs/current/screens/` | ترقية لـ `docs/current/spec.md`  
> **الفلسفة:** نافذة عائمة شفافة تحفظ سياق المشاهدة • جلب حي كامل من خادم Jellyfin • اختيار متعدد للتصنيفات بجانب البحث النصي • خلو تام من البيانات الثابتة  
> **المنصة:** هواتف أندرويد الذكية (Android Mobile Touchscreen)  
> **حالة الميزة:** معتمدة ومنفذة بالكامل

## 1. المعمارية البصرية للنافذة الشفافة (Modal Overlay Architecture)

1. **النافذة الحوارية العائمة (Transparent Dialog):**
   - تم إلغاء التنقل لصفحة مستقلة، وتحويل البحث إلى نافذة حوارية عائمة (`dialog` في `NavGraph`) ذات خلفية كربونية شبه شفافة مدخنة (`PureBlack` بنسبة 90% أو غشاء أوبسيديان شفاف).
   - تظل الشاشة الأصلية (الرئيسية، المكتبة، أو التفاصيل) مرئية بخفوت في الخلفية دون قطع تسلسل تجربة المستخدم.
   - إغلاق النافذة يتم بلمسة واحدة على المساحة الشفافة، أو زر الرجوع، أو إيماءة السحب للأسفل.

2. **زر التصنيفات المدمج والتحديد المتعدد (Trailing Filter Button):**
   - زر مدمج في نهاية شريط البحث بجانب زر المسح، مزود بشارة رقمية توضح عدد التصنيفات النشطة.
   - ينبثق منه ورقة سفلية (`GenrePickerBottomSheet`) تعرض كافة تصنيفات السيرفر الفعلية المجلوبة لحظياً عبر (`GET /Genres`).
   - إمكانية تحديد أكثر من تصنيف بالتوازي مع البحث النصي.
   - كبسولات نشطة قابلة للإزالة تظهر أسفل شريط البحث فور اختيار التصنيفات مع زر إزالة مباشر (×).

3. **استئصال البيانات الثابتة (Zero Hardcoded Data):**
   - إلغاء القوائم والكبسولات الثابتة بالكامل.
   - حتى شاشة الاستكشاف قبل الكتابة تجلب بياناتها حية: اقتراح عشوائي متجدد (`GET /Users/{userId}/Items?sortBy=Random`)، وسجل المستخدم الفعلي، وتصنيفات السيرفر الحقيقية.

## 3. عقد MVI وتدفق البيانات الحية

- **`SearchIntent`:**
  - `UpdateQuery(query)`
  - `Retry`
  - `ToggleGenre(genre)`
  - `RemoveGenre(genre)`
  - `ClearGenres`
  - `OpenGenrePicker` / `CloseGenrePicker`
  - `SelectRecentQuery(query)` / `DeleteRecentQuery(query)` / `ClearHistory`
  - `QuickPlay(mediaId)` / `OpenDetails(mediaId)`
  - `DismissSearch`
- **`SearchUiState`:**
  - `Idle`: يحمل `recentQueries`، و`availableGenres` الحية، و`spotlightItem` العشوائي.
  - `Searching`: يحمل `query` و`selectedGenres`.
  - `Success`: يحمل النتائج المفلترة بالنص والتصنيفات معاً.
  - `Empty`: حالة فارغة توضح عدم وجود نتائج تطابق النص مع التصنيفات.
  - `Error`: خطأ شبكة هادئ مع زر إعادة المحاولة.
