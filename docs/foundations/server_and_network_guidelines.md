# دليل ومعايير خادم الوسائط والشبكة المحلية
# Server & Local Network Optimization Guidelines (Jellyfin & MikroTik)

> **النطاق والبيئة المستهدفة:** شبكات الهوتسبوت المحلية (Hotspot) واستراحات الأحياء في اليمن.  
> **الهدف الهندسي الأساسي:** ضمان تشغيل عتادي مباشر بنسبة 100% (Hardware Direct Play)، وحظر إجهاد معالج السيرفر (Zero Transcoding)، ومنع اختناق روتر الوايفاي.

---

## 1. فلسفة التشغيل وحماية السيرفر

في بيئة الاستراحات وشبكات الأحياء:
* حاسوب خادم Jellyfin غالباً ما يكون جهازاً متوسط المواصفات؛ وأي عملية إعادة تشفير لحظية (Live Transcoding) متزامنة لعدة مستخدمين ستؤدي إلى ارتفاع حرارة المعالج لنسبة 100%، وبطء الشبكة، وتوقف الخدمة عن الجميع.
* روتر المايكروتك (MikroTik) والوايفاي هما شريان الاتصال؛ وترك الترافيك مفتوحاً دون إدارة للباندويث سيؤدي إلى اختناق بث الفيديو عند ذروة وجود الزبائن.
* حماية باقة الإنترنت الخارجي أمر حاسم؛ لذا يجب أن تظل كافة طلبات البث والبيانات محصورة 100% داخل الشبكة المحلية (LAN).

---

## 2. المعيار الذهبي لترميز مكتبات الفيديو (The Golden Encoding Standard)

لضمان عمل الوسائط على كافة هواتف أندرويد (الاقتصادية، المتوسطة، والحديثة) دون أي حاجة للترانزكود:

| العنصر | المواصفة الذهبية الموصى بها | السبب التقني والتشغيلي |
| :--- | :--- | :--- |
| **تشفير الفيديو** | `H.264 (AVC High Profile)` أو `H.265 (HEVC Main 8-bit)` | مدعوم بفك تشفير عتادي في 99% من هواتف أندرويد دون استهلاك بطارية. |
| **معدل البت (Bitrate)** | من `2.5` إلى `4.5` ميجابت/ثانية (لدقة 1080p) | يمنع تشبع قنوات الوايفاي ويسمح لـ 20-30 عميلاً بالمشاهدة المتزامنة. |
| **تشفير الصوت** | `AAC Stereo (192 kbps)` | يعمل بشكل أصيل على جميع الأجهزة دون الحاجة لتراخيص إضافية أو معالجة برمجية. |
| **الحاوية (Container)** | `MP4` أو `MKV` قياسي | حاويات قياسية سريعة القراءة مع دعم القفز الزمني الفوري (Fast Seeking). |
| **ملف الترجمة** | ملف خارجي بصيغة SubRip (`.srt`) مشفر بـ `UTF-8` | خفيف جداً، يقرأه مشغل التطبيق مباشرة دون دمج صوري (Burn-in) على السيرفر. |

---

## 3. أتمتة التحويل المسبق غير المتزامن (Pre-Transcoding Automation)

بدلاً من معالجة الفيديو لحظياً أثناء مشاهدة الزبائن، يتم تجهيز الملفات مسبقاً في أوقات فراغ السيرفر عبر الخطوات التالية:

### أ. سكربت FFmpeg لتحويل أي فيلم للصيغة القياسية بلمسة واحدة:
```bash
ffmpeg -i "input_movie.mkv" \
  -c:v libx264 -preset slow -crf 22 -maxrate 4.5M -bufsize 9M -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ac 2 \
  -c:s copy \
  "output_movie_direct_play.mp4"
```

### ب. استخراج الترجمة العربية كملف منفصل تلقائياً:
```bash
ffmpeg -i "input_movie.mkv" -map 0:s:m:language:ara "input_movie.ar.srt"
```

### ج. أتمتة المكتبة عبر Tdarr:
* تشغيل حاوية Docker لأداة `Tdarr` على السيرفر مع ضبط مسار المكتبات.
* تفعيل إضافة تحويل الملفات ليلاً تلقائياً إلى H.264/AAC Stereo واستخراج ملفات SRT فور تحميل أي فيلم تورنت جديد.

## 4. إعدادات خادم Jellyfin لحماية المعالج

يجب تطبيق الإعدادات التالية في لوحة تحكم Jellyfin (`Dashboard`):

1. **تقييد حساب الاستراحة المشترك (`الاستراحه`):**
   * الدخول إلى: `Dashboard -> Users -> الاستراحه`.
   * **إلغاء تفعيل:** `Allow video playback that requires transcoding`.
   * **إلغاء تفعيل:** `Allow audio playback that requires transcoding`.
   * **إلغاء تفعيل:** `Allow media deletion`.
   * **الفائدة:** إجبار الخادم على البث المباشر فقط؛ فإن كان الملف غير متوافق، يتولى التطبيق معالجته محلياً أو إبلاغ العميل بلباقة، ويظل السيرفر محمياً بنسبة 100%.

2. **تعطيل مهام الصيانة الثقيلة وقت الذروة:**
   * ضبط مهام فحص المكتبات وجلب الصور في: `Dashboard -> Scheduled Tasks` لتعمل حصراً في الساعات المتأخرة من الليل (مثلاً: بين 3:00 و 6:00 فجراً).

## 5. ضبط روتر المايكروتك وشبكة الوايفاي (MikroTik RouterOS)

لضمان عدالة التوزيع وثبات البث في الاستراحة:

### أ. تحديد سقف الباندويث لكل عميل عبر Simple Queue:
لمنع جهاز واحد من سحب كامل سعة الوايفاي عند تشغيل فيديو عالي الجودة:
```routeros
/queue simple
add name="Jellyfin_Local_Stream_Limit" target=192.168.200.0/24 \
    dst=192.168.200.200/32 max-limit=12M/12M queue=pcq-download-default/pcq-upload-default
```
*(هذا الإعداد يضمن حصول كل متصل على سقف أقصاه 12 ميجابت/ثانية، وهو كافٍ تماماً لجودة 1080p ناعمة مع ترك سعة كافية لبقية الزبائن).*

### ب. إتاحة السيرفر مجاناً دون الحاجة لكروت النت (Walled Garden):
إذا كانت الشبكة تعمل بنظام كروت الهوتسبوت (Hotspot Login)، يجب استثناء السيرفر حتى يتمكن الزبائن من فتح التطبيق ومشاهدة الوسائط حتى لو انتهى رصيد كرت النت الخارجي:
```routeros
/ip hotspot walled-garden ip
add action=accept dst-address=192.168.200.200 dst-port=80 comment="Jellyfin Free Local Access"
```

### ج. تقسيم ترددات الوايفاي (Band Segregation):
* **تردد 5GHz (اسم الشبكة مثلاً: `Estiraha_5G`):** يُخصص لأجهزة التلفاز الذكية وشاشات العرض والهواتف التي تدعم البث السريع، لمنع التداخل والتأخير.
* **تردد 2.4GHz (اسم الشبكة مثلاً: `Estiraha_2.4G`):** للتصفح العام وبقية الأجهزة.
