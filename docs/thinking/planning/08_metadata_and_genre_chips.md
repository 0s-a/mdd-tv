# نصوص البيانات الوصفية النقية وكبسولات التصنيفات التفاعلية
# Metadata Plain Text & Interactive Genre Chips Specification

> **المرجع والاستلهام:** أفضل ممارسات منصات البث العالمية (Netflix, Apple TV, Disney+) وتوجيهات الشاشات الكبيرة (10-Foot UI Experience).  
> **سجل الأفكار:** `docs/thinking/ideas/ideas_backlog.md` (المعرف: `IDEA-20`).  
> **الحالة:** مكتملة ومنفذة برمجياً (Implemented & Verified).  
> **النطاق:** واجهة تفاصيل العمل الفني (`MediaDetailsScreen`) ونظام التنقل والفلترة بالتصنيف (`SearchScreen`).

---

## 1. الرؤية والهدف الهندسي

تحقيق تجربة سينمائية راقية خالية من التشتيت البصري عبر إعادة توزيع أدوار المكونات البصرية:
1. **استئصال الشارات من البيانات الوصفية:** التوقف عن وضع حاويات أو كبسولات حول البيانات السردية للقراءة فقط (المدة، سنة الإنتاج، التقييم)، واستبدالها بنص نقي متصل مفصول بنقاط لطيفة (`•`).
2. **اعتماد الكبسولات التفاعلية (Interactive Chips / Pills) للتصنيفات:** تحويل التصنيفات (Genres) من نصوص جامدة إلى أزرار كبسولية تفاعلية تدعم التركيز بالريموت كنترول (D-pad Focus) وتفتح قائمة أعمال التصنيف عند الضغط.
3. **تبسيط الشارات التقنية:** استبدال شارات "مفتش بيانات الميديا" المعقدة بشارات خطية دقيقة ومفرغة (Subtle Outlines) للمواصفات الحقيقية (`4K`, `HDR`, `صوت محيطي`).

## 2. التحليل الفني والواقع الحالي في الكود (Gap Analysis)

* **في صفحة تفاصيل العمل (`MediaDetailsScreen.kt`):**
  * البيانات الوصفية تحتوي على إطارات غير متناسقة وتختلط مع شارات `InfuseTechBadgesRow` التي تستدعي نافذة سفلية معقدة (Inspector Bottom Sheet) تناقض مبدأ البساطة.
  * التصنيفات معروضة حالياً كنص مجرد: `Text(text = media.genres.joinToString(" • "))` غير قابل للنقر أو التركيز (Non-focusable).
* **في نظام التنقل (`NavGraph.kt` & `SearchScreen.kt`):**
  * `SearchViewModel` يمتلك بالفعل دالة جاهزة لجلب محتوى أي تصنيف: `SearchIntent.SelectGenre(genreName)`.
  * مسار البحث الحالي `Screen.Search` لا يستقبل معاملاً للتصنيف مباشرة، مما يستدعي تحديثه ليدعم `search?genre={genre}`.

## 4. مراحل خطة التنفيذ (Implementation Plan)

### المرحلة 1: بناء مكون كبسولة التصنيف (`GenreChip.kt`)
* إنشاء المكون داخل حزمة `presentation/details/components/`.
* تصميم الكبسولة بحواف دائرية أنيقة (`RoundedCornerShape(8.dp)` إلى `12.dp`).
* الحالة الافتراضية (Idle): خلفية كربونية داكنة مع نص واضح وقراءة مريحة من مسافة 3 أمتار.
* حالة التركيز بالريموت (Focused State):
  * تكبير طفيف بالحجم بمعدل `1.05x`.
  * خلفية عالية التباين (إما لون مشرق مع نص داكن أو إطار مضيء مشع).
* معالجة حدث الضغط وتمرير اسم التصنيف: `onClick: (String) -> Unit`.

### المرحلة 2: توسيع مسار البحث والفلترة بالتصنيف (`Navigation`)
* تحديث تعريف `Screen.Search` في `NavGraph.kt`:
  ```kotlin
  data object Search : Screen("search?genre={genre}") {
      fun createRoute(genre: String? = null): String =
          if (genre.isNullOrBlank()) "search" else "search?genre=${Uri.encode(genre)}"
  }
  ```
* في شاشة البحث `SearchScreen.kt`:
  * فحص وسيط `genre` القادم مع المسار، وإذا وُجد يتم إطلاق:
    `viewModel.processIntent(SearchIntent.SelectGenre(genre))`

### المرحلة 3: إعادة بناء منطقة البيانات في `MediaDetailsScreen.kt`
* **سطر البيانات الوصفية:**
  * إعادة ترتيب السطر ليكون نصاً ناصعاً ومريحاً ومفصولاً بنقاط وسطية (`•`):
    `تقييم IMDb • سنة الإنتاج • مدة العمل • التصنيف العمري`
* **صف كبسولات التصنيفات (Genres Row):**
  * استبدال النص المجرد بـ `LazyRow` مخصص للتصنيفات:
    * تباعد أفقي متزن (`Arrangement.spacedBy(8.dp)`).
    * عرض كل تصنيف عبر `GenreChip`.
    * عند النقر: `onNavigateToSearch(Screen.Search.createRoute(genre))`.
* **شارات الجودة التقنية:**
  * إزالة زر نافذة مفتش الميديا المعقدة بالكامل.
  * عرض إطارات خطية رقيقة ومفرغة (Outlined) للمواصفات الحقيقية (`4K UHD`, `HDR`, `صوت محيطي`).

### المرحلة 4: ضبط مسار التركيز بالريموت كنترول (D-Pad Focus Navigation)
* ضبط تسلسل مؤشر الريموت:
  * الصعود للأعلى من كبسولات التصنيفات ينقل المؤشر إلى أزرار الرجوع والمفضلة.
  * النزول للأسفل من كبسولات التصنيفات ينقل المؤشر مباشرة إلى زر "استئناف / تشغيل".
  * التنقل الجانبي (يسار/يمين) يتنقل بسلاسة وانسيابية بين الكبسولات دون احتجاز المؤشر.

### المرحلة 5: التحقق والاعتماد (Verification)
* التحقق من سلامة البناء البرمجي عبر `./gradlew assembleDebug`.
* التحقق البصري من هدوء الصفحة وانسيابية تجربة التنقل بالريموت.
* توثيق التعديل في `docs/current/screens/03_media_details.md` و `docs/UNRELEASED.md`.
