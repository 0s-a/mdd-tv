# شريط فصول الوسائط وعلامات التقدم السينمائي
# Media Chapters Timeline & Scrubbing Markers Specification

> **المرجع المعماري:** فكرة `IDEA-15` المعتمدة من مسار الأفكار والحزمة 6.  
> **الحالة المعمارية:** خطة تنفيذية معتمدة ومجدولة للمرحلة 4 (Approved - Phase 4 Roadmap).  
> **النطاق التقني:** مشغل الوسائط المدمج (`CinemaPlayerScreen`), مكون شريط التقدم (`CinemaScrubber`), واستخراج بيانات الوسائط من Jellyfin Item Chapters.  
> **المنصة المستهدفة:** Native Android • هواتف أندرويد الذكية والأجهزة اللوحية (Touchscreen First).

---

## 1. الرؤية والهدف الهندسي

تمكين المشاهد من التصفح السريع والذكي لأجزاء العمل الفني (مثل المقدمة، الفصول الدرامية الرئيسية، وشارة النهاية) عبر استخراج علامات الفصول (Chapters) المخزنة في خادم Jellyfin أو داخل حاوية الفيديو (MKV / MP4)، ورسمها كفواصل بصرية هادئة جداً على شريط التقدم، مع إظهار اسم الفصل الحالي في نافذة عائمة مرافقة لحركة الإصبع.

---

## 2. الركائز التصميمية والفنية

### أ. الفواصل الصامتة على شريط التقدم (Chapter Markers)
* رسم خطوط عمودية فائقة الرقة (1dp إلى 1.5dp) باللون الأبيض شبه الشفاف (`0x4DFFFFFF`) عند النقاط الزمنية لبداية كل فصل على شريط `CinemaScrubber`.
* تجنب أي قطوع حادة أو نتوءات مشوهة لشريط التقدم.

### ب. بطاقة الفصل العائمة (Floating Chapter Card)
* عند لمس وسحب شريط التقدم، تظهر بطاقة صغيرة هادئة أعلى مؤشر السحب تعرض:
  * اسم الفصل (مثال: `المقدمة`، `الفصل 3: المواجهة`، `شارة النهاية`).
  * التوقيت الرقمي الدقيق.
* تندمج البطاقة بسلاسة مع نافذة المعاينة الصورية `TrickplayPreviewCard` بحيث يظهر اسم الفصل أسفل لقطة المشهد مباشرة دون ازدحام.

### ج. واجهة استخراج البيانات (Data Contract)
* قراءة حقل `Chapters` من كائن `MediaItem` أو استجابة `GET /Items/{id}`:
  ```kotlin
  data class MediaChapter(
      val name: String,
      val startPositionTicks: Long
  )
  ```
* حساب الفصل الحالي لحظياً أثناء التشغيل والسحب بعملية بحث ثنائي سريعة $O(\log n)$.
