# مسار الأفكار والدراسات الأولية
# Ideas & Initial Proposals Hub

مسار استقبال وتدوين الأفكار الجديدة والمقترحات المبتكرة لتطبيق "مدد TV" قبل نقلها إلى التخطيط المعماري المعتمد.

---

## 1. فلسفة المسار وقواعد الإضافة

* **حرية الطرح والابتكار:** يمثل هذا المسار منصة مفتوحة لتدوين أي فكرة تطويرية، ميزة جديدة، أو مقترح لتحسين تجربة المستخدم.
* **الفحص المعماري الصارم:** لا تنتقل أي فكرة إلى مرحلة التخطيط التنفيذي إلا بعد اجتياز الفحص المعماري الصارم بواسطة وكيل التفكير والفرز المعماري (`thinking-architect`).
* **استخدام القالب المعتمد:** عند طرح أي فكرة جديدة، ينشأ مسودة ملف باسم الفكرة بنمط `snake_case.md` مستنداً إلى [`template_idea_analysis.md`](./template_idea_analysis.md).
* **قاعدة الترقية والنقل وعدم التكرار (Zero Duplication):** فور اعتماد الفكرة معمارياً، **تُنقل الوثيقة بالكامل** إلى مجلد التخطيط [`../planning/`](../planning/) برقم تسلسلي، ويُحدث سجل [`ideas_backlog.md`](./ideas_backlog.md)، ويُمنع منعاً باتاً ترك نسخ مكررة داخل هذا المجلد.

---

## 2. كيفية إضافة فكرة جديدة وتفعيل الوكيل

1. قم بإنشاء ملف جديد في هذا المجلد: `docs/thinking/ideas/your_idea_name.md`.
2. املأ القسم الأول فقط (وصف الفكرة، الدافع، والقيمة المضافة) مستعيناً بالقالب [`template_idea_analysis.md`](./template_idea_analysis.md).
3. قم بتشغيل أو توجيه الوكيل المخصص (`thinking-architect`) لمباشرة دراسة الفكرة وفحص تعارضاتها ونقاط فصلها.
4. بمجرد اكتمال الفحص والموافقة المعمارية:
   * تُنقل الوثيقة بالكامل إلى مجلد التخطيط [`../planning/`](../planning/) برقم تسلسلي معتمد.
   * في حال رفض الفكرة، تُنقل إلى مجلد المستبعدات [`../archive/rejected/`](../archive/rejected/) مع توثيق الأسباب.
   * يُحدث سجل المتابعة الشامل [`ideas_backlog.md`](./ideas_backlog.md).

---

## 3. محتويات المجلد المرجعية

* [`template_idea_analysis.md`](./template_idea_analysis.md): القالب القياسي لدراسة الأفكار وفحص التعارضات والعزل.
* [`ideas_backlog.md`](./ideas_backlog.md): مصفوفة وجدول حصر الأفكار والمقترحات الشاملة لكافة المراحل.
