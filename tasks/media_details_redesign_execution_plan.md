## Master Implementation & Execution Plan: Media Details Redesign Suite

> **النطاق:** خطة تنفيذ هندسية موجهة لتطوير وتحديث كافة شاشات تفاصيل الوسائط بالتوازي.  
> **المشروع:** مدد TV (`mdd_tv`) • أندرويد Jetpack Compose • نظام OLED True Black.  
> **المرجع المعماري المعتمد:** [`docs/current/screens/media_details/00_general_layout_architecture.md`](../docs/current/screens/media_details/00_general_layout_architecture.md)

## 1. أهداف الخطة وميثاق الجودة البرمجية

1. **الالتزام بالقالب الموحد الموروث:** (الغلاف 50% مع الأيقونات الخالصة، الشريط العلوي المقتضب، زر التشغيل المنفرد 54dp، والصف الثنائي المتناظر).
2. **الحظر الشامل للإيموجيات (Absolute Emoji Ban):** منع أي إيموجيات في الكود، التعليقات، النصوص البرمجية، ورسائل الـ Commit.
3. **الاستقرار والتجميع الخالي من الأخطاء (Zero Regression):** اجتياز كافة اختبارات الوحدة (`testDebugUnitTest`) بنسبة 100% بعد كل تعديل.
4. **عزل البيانات محلياً (Local-First Data Isolation - Room DB):** حماية حساب السيرفر المشترك عبر حفظ المفضلة وحالة المشاهدة محلياً.

## 2. مراحل خطة العمل البرمجية (Execution Phases)

### المرحلة 0: المكونات الهيكلية المشتركة (Shared Foundation Components)
* **المهمة 0.1:** إنشاء وتطوير نافذة الحفظ الموحدة المنبثقة (`SaveModalBottomSheet.kt`) لتمكين الاختيار بين: المفضلة و قائمتي (Watchlist).
* **المهمة 0.2:** تطوير قائمة الإجراءات العلوية المنسدلة الموحدة (`TopActionsDropdownMenu.kt`) التي تحتوي على: خيارات الصوت والترجمة، المشاركة، تمت المشاهدة، والتريلر المشروط.

---

### المسارات التنفيذية المتزامنة للشاشات (Parallel Track Execution)

#### المسار الأول: شاشة تفاصيل الأفلام (`MovieDetailsScreen.kt`)
* **الملفات المستهدفة:**
  * `presentation/details/movie/MovieDetailsScreen.kt`
  * `presentation/details/movie/MovieDetailsContract.kt`
* **المهام البرمجية:**
  1. تحديث الشريط العلوي ليعتمد على زر القائمة المنسدلة الثلاثي وإزالة أزرار المفضلة والمشاركة المنفصلة.
  2. ضبط الغلاف على 50% من ارتفاع الشاشة والتنقل بالأيقونات الخالصة.
  3. بناء صف التشغيل المنفرد العريض (أبيض عاجي 54dp) بنص "تشغيل" أو "استئناف".
  4. بناء الصف الثنائي المتناظر: (زر "حفظ في القوائم" + زر "مشغل خارجي").

#### المسار الثاني: شاشة تفاصيل المسلسلات والمواسم (`SeriesDetailsScreen.kt`)
* **الملفات المستهدفة:**
  * `presentation/details/series/SeriesDetailsScreen.kt`
  * `presentation/details/series/SeriesDetailsContract.kt`
* **المهام البرمجية:**
  1. تحديث الشريط العلوي للقالب الموحد.
  2. ترقية زر التشغيل الرئيسي إلى زر الاستئناف الذكي المنفرد: "استئناف: ح X · م Y" (أو بدء الحلقة الأولى).
  3. ضبط الصف الثنائي المتناظر: (حفظ في القوائم + مشغل خارجي للحلقة التالية).
  4. صقل محدد المواسم الهجين (كبسولات أفقية + قائمة منسدلة).
  5. تحسين قائمة الحلقات الرأسية وإبراز زر تمييز المشاهدة الفردي لكل حلقة (Checkbox 48dp).

#### المسار الثالث: شاشة تفاصيل السلاسل والمجموعات (`BoxSetDetailsScreen.kt`)
* **الملفات المستهدفة:**
  * `presentation/details/boxset/BoxSetDetailsScreen.kt`
  * `presentation/details/boxset/BoxSetDetailsContract.kt`
* **المهام البرمجية:**
  1. وراثة الغلاف 50% والشريط العلوي المقتضب.
  2. بناء زر المتابعة الذكي المنفرد: "متابعة: [اسم الجزء التالي]" أو بدء السلسلة.
  3. ضبط سطر الإحصائيات التراكمية (عدد الأجزاء، إجمالي الساعات).
  4. صقل بطاقات الأجزاء المرتبة زمنياً مع أزرار التشغيل السريع المدمجة.

#### المسار الرابع: شاشة تفاصيل الألبومات والموسيقى (`MusicAlbumDetailsScreen.kt`)
* **الملفات المستهدفة:**
  * `presentation/details/music/MusicAlbumDetailsScreen.kt`
  * `presentation/details/music/MusicAlbumDetailsContract.kt`
* **المهام البرمجية:**
  1. تثبيت الغلاف المربع 1:1 في المنتصف العلوي مع الهالة الضوئية.
  2. بناء صف التشغيل المنفرد: "تشغيل الألبوم" (أو استئناف).
  3. بناء الصف الثنائي: (خلط عشوائي Shuffle + حفظ في القوائم).
  4. ضبط قائمة المسارات المرقمة وإبراز التراك النشط بلون ذهبي والمشغل المصغر الدائم (64dp).

## 3. التحقق النهائي ومعايير الإغلاق (Verification & Acceptance Criteria)

1. اختبار كافة الشاشات على شاشات هواتف متعددة الأبعاد (من 360dp إلى 430dp عرضاً).
2. التأكد من استجابة أهداف اللمس (لا يقل أي هدف لمس عن `48dp x 48dp`).
3. التأكد من عمل المشغل الخارجي والتنقل السلس دون تعليق.
4. اجتياز اختبارات الوحدة التلقائية `./gradlew testDebugUnitTest` بنجاح 100%.
