# خطة الإصلاح الاحترافية والمعمارية لتصميم وتفاعل المشغل السينمائي
# Professional Remediation Plan for Cinema Player Design & Interaction (Streamlined Minimal HUD)

> **نطاق العمل:** منظومة المشغل السينمائي في `mdd_tv` (`presentation/player/` و `core/player/`).
> **المرجع الهندسي:** وثيقة مواصفات الشاشة `docs/current/screens/04_advanced_player.md` ودستور المشغل المتقدم `docs/thinking/planning/advanced_cinema_player_master_plan.md`.
> **الفلسفة الجديدة المعتمدة:** التجريد والهدوء البصري الأقصى (Ultra-Minimalist Cinema HUD) — إلغاء شريط الكبسولات السفلي بالكامل، تفريغ الشاشة لمتعة المشاهدة، وتوحيد كافة الإجراءات داخل زر إجراءات مركزي يفتح قائمة مبسطة تتفرع منها نوافذ صغيرة مركزة بحسب طبيعة كل إجراء.
> **المحددات الدستورية:** العزل التام للمشروع (Root Isolation Law)، الحظر الشامل للإيموجيات (Absolute Emoji Ban)، والاستقرار التام لنمط MVI.

---

## 1. فلسفة التصميم الجديدة: التخلص من ازدحام الكبسولات (De-cluttering Manifesto)

```
[الشكل السابق المزدحم]:
شريط علوي (5 أزرار) + تحكم وسطي + شريط تقدم + شريط كبسولات سفلي عائم (6 كبسولات وأزرار) + نوافذ متكررة.

                 │
                 ▼ التحول الجذري المعتمد

[الشكل السينمائي النقي الجديد (Ultra-Clean)]:
┌────────────────────────────────────────────────────────────────────────┐
│ [<- رجوع]  اسم الفيلم / المسلسل (2024)            [قفل] [تدوير] [إجراءات]│
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                  (<< 10s)       [ > / || ]       (10s >>)              │
│                                                                        │
│                      "الترجمة العربية بالحد الأسود المانع للوهج"        │
│                                                                        │
│  42:15 ────────────────────────●──────────────────────────── 02:18:40  │
└────────────────────────────────────────────────────────────────────────┘
```

### جوهر التعديل الهندسي:
1. **تفريغ الشريط السفلي بالكامل:** إزالة شريط الكبسولات العائم (`MxQuickChip`)؛ ليبقى أسفل الشاشة مخصصاً فقط للخط الزمني النقي وأوقات التشغيل.
2. **توحيد الدخول عبر زر الإجراءات (Single Actions Entry Point):** زر واحد في أعلى الشاشة يفتح قائمة سفلية مصغرة هادئة.
3. **نوافذ منبثقة مركزة ومستقلة (Dedicated Micro-Sheets):**
   * **نافذة الترجمة:** اختيار المسار ومزامنة التوقيت `±100ms`.
   * **نافذة الصوت:** اختيار المسار، المزامنة `±50ms`، ومفتاح التمرير المباشر (Bitstream).
   * **نافذة السرعة:** أزرار اختيار سريعة (0.5x إلى 2.0x).
   * **نافذة المعادل الصوتي:** أعمدة الترددات الخمسة وزر تعزيز الحوار (Vocal Boost).
   * **إجراءات مباشرة بنقرة واحدة:** تبديل أبعاد الشاشة (Fit/Fill)، وتفعيل صورة داخل صورة (PiP)، والمشغل الخارجي.

## 3. تفاصيل المراحل التنفيذية الأربع (Phased Remediation Breakdown)

### المرحلة 1: تبسيط شريط التحكم وإلغاء الكبسولات وتفعيل التلاشي (3s Auto-Dismiss)

#### المهام التنفيذية:
1. **في `PlayerHudOverlay.kt`:**
   * حذف حاوية الكبسولات السفلية بالكامل (`MxQuickChip` capsule row).
   * الإبقاء على شريط التقدم الفصلي `CinemaScrubber` والعداد الزمني المزدوج (الوقت المنقضي / الوقت المتبقي) فقط.
   * حذف الأزرار المكررة من الشريط العلوي (زر الترجمة المكرر) وحصر كافة الإعدادات في زر "الإجراءات".
2. **في `AdvancedPlayerScreen.kt`:**
   * تفعيل مؤقت الخمول 3 ثوانٍ (`LaunchedEffect(isPlaying, isHudVisible)`) مع تصفير العداد عند كل لمسة، لإخفاء عناصر التحكم تلقائياً أثناء تشغيل الفيديو.
3. **في `GestureOverlayHud.kt`:**
   * استبدال الدوائر البدائية بأيقونات السطوع (`Icons.Rounded.LightMode`) والصوت (`Icons.AutoMirrored.Rounded.VolumeUp` و `VolumeOff`).

#### معايير القبول والتحقق:
- [x] شاشة المشغل نقية تماماً وخالية من أي كبسولات أو أزرار عائمة زائدة.
- [x] شريط التحكم يختفي تلقائياً وبشكل كامل بعد 3 ثوانٍ من عدم التفاعل أثناء التشغيل.
- [x] مؤشرات الإيماءات اللمسية تظهر بأيقونات Material واضحة للسطوع والصوت.

---

### المرحلة 2: بناء قائمة الإجراءات الموحدة والنوافذ المصغرة المركزة

#### المهام التنفيذية:
1. **إعادة بناء `PlayerActionsModal.kt` كقائمة إجراءات موحدة رئيسية:**
   * قائمة عمودية أنيقة تفتح كـ Bottom Sheet مصغر بهوية OLED وسواد نقي:
     * **الترجمة:** يعرض المسار النشط حالياً، وعند النقر يفتح نافذة الترجمة المصغرة.
     * **الصوت:** يعرض المسار الصوتي النشط، وعند النقر يفتح نافذة الصوت المصغرة.
     * **أبعاد الشاشة:** تبديل فوري مباشر بين (العرض الأصلي / ملء الشاشة).
     * **سرعة التشغيل:** يعرض السرعة الحالية (مثل 1.0x)، وعند النقر يفتح نافذة السرعة.
     * **معادل الصوت:** فتح نافذة معادل الترددات الصوتي وتعزيز الحوار.
     * **صورة داخل صورة (PiP):** تفعيل مباشر للنافذة العائمة.
     * **مشغل خارجي:** نقل البث إلى مشغل النظام أو المشغلات الخارجية.
2. **تصميم النوافذ المصغرة المركزة (Dedicated Micro-Dialogs):**
   * **نافذة الترجمة:** قائمة مسارات نظيفة مع أزرار مزامنة دقيقة `±100ms` وخيار إيقاف الترجمة.
   * **نافذة الصوت:** قائمة اللغات، مزامنة الصوت `±50ms`، ومفتاح التمرير المباشر (Bitstream).
   * **نافذة السرعة:** كبسولات اختيار مباشر لسرعات (0.5x, 0.75x, 1.0x, 1.25x, 1.5x, 2.0x).
   * **نافذة المعادل الصوتي:** أعمدة رأسية خماسية واضحة وزر "تعزيز الحوار" (Vocal Boost).
3. **التعريب الكامل:** تعريب 100% لكافة النصوص والمصطلحات.

#### معايير القبول والتحقق:
- [x] قائمة الإجراءات خفيفة، هادئة، وسريعة الاستجابة.
- [x] كل خيار يفتح نافذة صغيرة متخصصة به دون تشويش المشاهد بباقي الإعدادات غير المعنية.
- [x] خلو كافة الواجهات من أي نصوص إنجليزية غير تقنية.
