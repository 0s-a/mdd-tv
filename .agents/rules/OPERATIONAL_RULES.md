# قواعد العمل وسلوك الوكيل الذكي
# Operational Rules & Agent Governance

> مرجع إلزامي لقواعد العمل والسلوك المهني داخل المشروع.

---

## 1. الحظر الشامل للإيموجيات (Absolute Emoji Ban)

يُمنع منعاً باتاً وبدون أي استثناء استخدام الإيموجيات أو الرموز التعبيرية في:
* أسماء الملفات والمجلدات.
* الكود البرمجي والتعليقات (Code Comments).
* رسائل وسجلات التشغيل (Log Messages).
* رسائل التثبيت في Git (Commit Messages).
* التوثيق وملفات الـ Markdown.
* ردود ومخرجات الوكلاء الأذكياء.

---

## 2. معايير تسمية الملفات والمجلدات (Naming Conventions)

* **المجلدات:** أحرف إنجليزية صغيرة بنمط `snake_case` فقط (مثل `server_test_suite`, `ui_references`).
* **الملفات الفرعية والوثائق المتسلسلة:** نمط `snake_case.md` مع ترقيم تسلسلي عند الحاجة (مثل `01_home_screen.md`).
* **الملفات الدستورية والمرجعية الكبرى:** نمط `SCREAMING_SNAKE_CASE.md` (مثل `README.md`, `SPEC.md`, `OPERATIONAL_RULES.md`).
* **الكلاسات والواجهات البرمجية:** نمط `PascalCase` الصارم.
* **الدوال والمتغيرات:** نمط `camelCase`.
* **موارد النظام (Resources):** نمط `snake_case` بأحرف صغيرة وأرقام فقط دون رموز خاصة.
* **منع المسافات:** يُحظر استخدام المسافات أو الرموز الخاصة في التسمية نهائياً.

---

## 3. معايير الـ Git ونمط رسائل الكوميت (Git Commit Standards)

* الالتزام الصارم بنمط Conventional Commits القياسي باللغة الإنجليزية:
  `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`, `perf:`.
* رسائل واضحة ومباشرة تصف التغيير دون حشو ودون أي رموز تعبيرية.

---

## 4. الانضباط بالنطاق وعدم التشتت (Scope Adherence & Zero Drift)

* العمل يتم حصراً وفق المهام والمواصفات المحددة في مجلدات التوثيق والمهام (`docs/`, `tasks/`).
* يُمنع اختراع متطلبات جديدة، أو إضافة مكتبات خارجية غير مطلوبة، أو اتخاذ قرارات معمارية دون توجيه صريح.

---

## 5. حظر خلط مواصفات التطبيق بقواعد العمل (Strict Separation of Specs and Rules)

* تُعزل مواصفات ومتطلبات التطبيق الفنية، المعمارية، ونظام التصميم تماماً وتتواجد حصراً داخل مجلد التوثيق (`docs/`).
* يُمنع منعاً باتاً دمج أو كتابة أي تفاصيل تقنية خاصة بالتطبيق (مثل المكتبات، المعمارية، الشاشات، أو إعدادات السيرفر) داخل وثائق وقواعد العمل وسلوك الوكيل (`OPERATIONAL_RULES.md` أو ملفات الحوكمة).
